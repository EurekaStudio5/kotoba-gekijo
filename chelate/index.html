Chelate AI Works 自動投稿

「Chelate AI Works 自動投稿」は、Chelate AI Works が自分のYouTubeチャンネルへ、自分で制作した動画を投稿し、再生数などの統計を見るための社内ツールです。第三者の利用は想定していません。

YouTube Data API と YouTube Analytics API を使い、自分のチャンネルの動画のアップロード・管理と、統計の取得だけを行います。

English

"Chelate AI Works 自動投稿" (Chelate AI Works Auto Upload) is an internal tool that Chelate AI Works uses to upload videos it has produced itself to its own YouTube channels, and to view statistics such as view counts. It is not intended for use by third parties.

It uses the YouTube Data API and the YouTube Analytics API only to upload and manage videos on our own channels and to retrieve their statistics.
