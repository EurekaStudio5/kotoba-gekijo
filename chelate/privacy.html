日本語

本ポリシーは、Chelate AI Works（以下「当方」）が使う「Chelate AI Works 自動投稿」（以下「本ツール」）での情報の取り扱いを説明します。

本ツールは、当方が自分のYouTubeチャンネルへ、自分で制作した動画を投稿し、再生数などの統計を見るための社内ツールです。第三者の利用は想定していません。

扱うデータ：本ツールは、Google の YouTube Data API と YouTube Analytics API を使い、当方のチャンネルについて次のことだけを行います。

  • 動画のアップロードと管理（タイトル・説明・公開設定など）：YouTube Data API
  • 再生数などの統計の取得：YouTube Analytics API
  • 上記に必要なチャンネルの基本情報（チャンネルID・チャンネル名）と、Google が発行するアクセストークンの利用

第三者の情報：本ツールは、視聴者や他のユーザーの個人情報を集めません。

保存：取得したデータとアクセストークンは、当方が管理するPCの中にだけ保存します。

販売・共有：取得したデータを販売したり、第三者と共有したりしません。

アクセスの取り消し：Google アカウントの「サードパーティ製のアプリとサービス」（myaccount.google.com/connections）から、本ツールのアクセスをいつでも外せます。

関連する規約：本ツールは YouTube API サービスを利用しています。あわせてGoogle プライバシーポリシーとYouTube 利用規約をご確認ください。

お問い合わせ：GitHub の Issuesからご連絡ください。

English

This policy explains how information is handled in "Chelate AI Works 自動投稿" (Chelate AI Works Auto Upload, the "Tool"), which is used by Chelate AI Works ("we").

The Tool is an internal tool that we use to upload videos we have produced ourselves to our own YouTube channels, and to view statistics such as view counts. It is not intended for use by third parties.

Data we handle: The Tool uses Google's YouTube Data API and YouTube Analytics API, and only does the following for our own channels:

  • Uploading and managing videos (title, description, privacy status, etc.): YouTube Data API
  • Retrieving statistics such as view counts: YouTube Analytics API
  • Using the basic channel information needed for the above (channel ID and channel name) and the access tokens issued by Google

Third-party data: The Tool does not collect personal information of viewers or other users.

Storage: The data and access tokens we obtain are stored only on PCs that we control.

Sale and sharing: We do not sell the data we obtain or share it with third parties.

Revoking access: You can remove the Tool's access at any time from "Third-party apps & services" in your Google Account (myaccount.google.com/connections).

Related terms: The Tool uses YouTube API Services. Please also see the Google Privacy Policy and the YouTube Terms of Service.

Contact: Please contact us via GitHub Issues.
